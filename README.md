# 行情与限购看板

纳斯达克100 / 标普500 / 黄金的实时行情与历史走势,叠加国内 QDII 基金每日限购额度跟踪。

## 功能

- **实时行情**:纳指100、标普500(腾讯财经)、标普红利低波50ETF联接A(天天基金净值,场内交易日按母基金 ETF 涨跌盘中估算)+ 金价(新浪财经,默认沪金主力,可切伦敦金现),页面 5 分钟自动刷新,支持手动刷新
- **历史走势**:3个月 / 6个月 / 1年 / 3年 切换,叠加 250日均线(年线,默认显示)与 20日均线(月线,默认隐藏,点图例显示),纳指100 / 标普500 图上显示当前 PE 与历史百分位;红利低波50联接 图可点图例叠加 **股息率(估)** 与 **股债利差(估)**(默认隐藏,右轴百分比;官方无历史股息率,按 当前股息率×当日PE/当前PE 反推,假设分红比例稳定),利差 = 股息率 − 中国10年期国债收益率;图内可拖拽缩放(ECharts)
- **限购额度**:自动发现全市场跟踪纳指100 / 标普500的 QDII 场外基金(人民币份额,含 A/C/D/E/I 类),按 [QDII 额度雷达](https://www.trendkitlab.com/p/qdii-quota-radar/)口径展示 开放申购 / 限大额(限额内仍可买)两类可买列表与每日额度,暂停申购的隐藏(顶部有计数);另展示美股/纳斯达克主动基金的限额、当日涨跌幅(最新净值日增长,QDII 为 T-1)、基金规模与区域占比,支持按 限额/涨跌幅/美股占比 排序,同样只列可申购的——名单=名称含"纳斯达克"非100(华宝纳斯达克精选、纳斯达克科技/生物科技联接)+ 手工核对的美股方向主动 QDII(嘉实美国成长、汇添富全球移动互联、广发全球精选、华宝致远、银华海外数字经济量化、工银全球精选等,见 `funds.ts` 的 `ACTIVE_EXTRA`);区域分布=最新中报/年报**全持仓**按市场归类占净值比(美股 105/106/107、港股 116、A股 0/1、其它,披露滞后约半年),只显示非零区域,联接基金不披露股票持仓显示"—";每日定时全量入库

## 技术栈

Next.js 14(App Router + TypeScript)+ Tailwind CSS + ECharts + Neon Postgres(免数据库时行情功能照常,限购历史降级)

## 本地开发

```bash
npm install
npm run dev          # 打开 http://localhost:3000
npm run cron:daily   # 手动触发一次限购抓取(需已配置 DATABASE_URL)
```

## 数据库配置(限购历史功能)

1. 到 [neon.tech](https://neon.tech) 免费注册,创建一个 Project
2. 复制 Connection String(形如 `postgresql://user:pass@ep-xxx.neon.tech/neondb?sslmode=require`)
3. 本地:复制 `.env.example` 为 `.env.local`,填入 `DATABASE_URL=...`
4. 访问一次 `/api/cron/daily`,数据表自动创建并写入当天记录

不配置数据库时所有限购数据来自页面访问时的实时抓取,**不保留历史**;配置后 cron 每日入库,可查看近 60 天额度变化。数据库完全可选。

## 跟踪范围

基金列表自动发现:按天天基金全量代码表中基金名称匹配 `纳斯达克100` / `标普500`,排除美元份额、等权重指数、场内 ETF(仅保留"ETF联接"场外份额)。调整范围编辑 `src/lib/funds.ts` 的 `INDEX_RULES`。

## 部署到 Vercel

```bash
npm i -g vercel
vercel                # 首次登录并 link 项目
vercel env add DATABASE_URL     # 粘贴 Neon 连接串
vercel --prod         # 部署
```

`vercel.json` 已配置 cron:每天 UTC 14:00(北京时间 22:00)自动抓取当日限购额度,覆盖当日基金公司最终的限额状态。

可选:设置 `CRON_SECRET` 环境变量后,cron 接口会校验 Bearer Token,防止被外部随意触发。

## 数据源说明

| 数据 | 来源 | 说明 |
|---|---|---|
| 纳指100 / 标普500 实时+日K | 腾讯财经 `qt.gtimg.cn` / `web.ifzq.gtimg.cn` | 免费公开接口,无需 key |
| 标普红利低波50ETF联接A 净值+历史 | 天天基金(008163,南方基金) | 场外单位净值,元,4 位小数,日更;场内交易日盘中/收盘后按母基金 ETF(腾讯 sh515450)涨跌估算当日净值与高低,官方净值公布后自动切回 |
| 沪金主力实时+日K | 新浪财经 `hq.sinajs.cn`(nf_AU0)/ 新浪国内期货(AU0) | 元/克,涨跌按昨结算价计算 |
| 伦敦金现实时 | 新浪财经 `hq.sinajs.cn`(hf_XAU) | 需要 Referer 头 |
| 伦敦金日K | 新浪全球期货(XAU) | 2006 年至今 |
| 指数估值(PE) | 蛋卷指数估值 `danjuanfunds.com` | 纳指100 / 标普500 当前 PE + 历史百分位,日更,缓存 1 小时;红利低波当前股息率同源(CSIH30269) |
| 中证红利低波 PE 历史 | 中证指数官网 `csindex.com.cn` | 日频,2013 年至今,缓存 12 小时;用于反推股息率历史 |
| 中国10年期国债收益率 | 东财数据中心 `datacenter.eastmoney.com` | 股债利差的债券端,缓存 12 小时 |
| 限购基金名单 | 天天基金全量代码表 `fund.eastmoney.com/js/fundcode_search.js` | 每日缓存一次,按名称匹配指数 |
| 申购状态 + 每日额度 | 天天基金费率页 `fundf10.eastmoney.com` | 申购状态表格优先于旧限额文本,状态缓存 10 分钟 |
| 基金当日涨跌幅 | 东财 F10 历史净值 `api.fund.eastmoney.com` | 最新单位净值日增长率(QDII 为 T-1),缓存 1 小时 |
| 区域分布(美股/港股/A股/其它) | 东财 F10 持仓 `fundf10.eastmoney.com`(jjcc, month=6) | 中报/年报全持仓按市场前缀归类,缓存 1 天 |
